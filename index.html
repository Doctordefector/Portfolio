Lyrenne

A free YouTube Music player for Windows and Linux, written in Compose Desktop on the JVM. It has its own VLC playback engine, a local database and two-way library sync, not a browser wrapper. Synced lyrics, a 10-band equalizer, offline downloads, Discord Rich Presence and Listen Together rooms.

  • iPad: a SwiftUI and AVPlayer port with its own InnerTube client, offline downloads and a hand-rolled protobuf Listen Together client.
  • Steam Deck: a Decky Loader plugin that controls a headless Lyrenne build over localhost from the Game Mode menu. About 250 MB of RAM while playing.
  • Distributed through GitHub Releases, Scoop and winget.

Hanko 判子

A bag charm with a swappable cap and an NFC chip inside. Two people tap phones and swap profile cards instead of social handles. Each meeting adds to a shared history, and socials only unlock when both people agree. There's no app to install and no location tracking.

I built the product: the web app the charm opens, the card designer, the admin and charm-minting tools, and the 3D models for the printed parts.

  • Node 22 with zero dependencies (built-in node:sqlite), web push, deployed on Render.
  • Automated QA that screenshots every page on 7 phone sizes, a contrast checker, and a simulated playtest of a whole school.
  • Blender pipeline for product renders and printable STLs.
